# 第一课：原始 CNN 如何把胸片变成分类结果

本课只解释 `notebooks/baselines/cnn.ipynb`。没有启动训练，也没有声称新模型成绩。任务是根据给定标签预测 NORMAL 或 PNEUMONIA，不是证明某个位置存在病灶。

## 1. 先看一张图如何进入网络

原始文件可能是灰度 L，也可能是 RGB。原 Keras 目录加载器默认输出 RGB，所以送入模型的是 **100×100×3**：100 行、100 列、3 个颜色通道。灰度图转 RGB 后三个通道通常相同，不代表获得三种新医学信息。原代码直接缩放为正方形，会改变部分图像的宽高比例；本次同结构基线保留这个选择。

原像素约在 0–255，除以 255 后在 0–1。它改变数值尺度，不改变图像的空间结构。训练时一次输入多个样本：原 Keras 使用 `(B,100,100,3)`；后续 PyTorch 使用 `(B,3,100,100)`，B 是 batch size。

## 2. 卷积：同一组小规则扫描不同位置

第一层有 32 个卷积核，每个卷积核覆盖 3×3 的空间区域，同时读取全部 3 个输入通道。一个卷积核在每个位置产生一个数字，扫描完整张图后形成一张特征图；32 个卷积核产生 32 个输出通道。

每个局部输出是加权求和再加偏置：

`z[o,h,w] = b[o] + Σ W[o,c,i,j] × x[c,h+i,w+j]`

对输入通道 c 和窗口位置 i、j 求和。卷积核数值通过训练学习，不是我们手动指定“识别肺炎”的规则。浅层可能响应边缘或纹理，但不能把某个通道直接当作可验证的医学概念。

空间输出尺寸公式：

`out = floor((in + 2×padding − dilation×(kernel−1) − 1) / stride + 1)`

原卷积 kernel=3、stride=1、padding=0、dilation=1，因此 100 变成 98。不要把输出误认为仍是 100。

## 3. ReLU、池化和 Dropout 各做什么

- **ReLU：**`max(0,z)`，使网络具有非线性，尺寸不变。如果只叠加线性运算，网络整体仍然是线性映射。
- **MaxPool：**每个 2×2 区域选最大值，步长为 2。例如 `[1,3;2,0]` 变成 `3`。它缩小空间尺寸，没有可学习参数；49 经池化为 24，但本项目第二次池化前已经卷积成 47，所以实际得到 23。
- **Dropout：**训练时随机置零部分激活，减少模型依赖少数特征。`0.2` 表示丢弃概率，不是每次精确删除 20% 的神经元；保留值会做缩放。评估时关闭 Dropout，因此推理必须切换到评估模式。

## 4. 逐层尺寸和参数量

以下尺寸为单张图的 H×W×C。每个卷积后有 ReLU，每次池化后有 Dropout(0.2)，这些步骤不增加可学习参数。

| 层 | 输出尺寸 | 参数量 |
| --- | --- | ---: |
| 输入 | 100×100×3 | 0 |
| Conv1，3×3，3→32 | 98×98×32 | 896 |
| MaxPool1 | 49×49×32 | 0 |
| Conv2，3×3，32→32 | 47×47×32 | 9,248 |
| MaxPool2 | 23×23×32 | 0 |
| Conv3，3×3，32→64 | 21×21×64 | 18,496 |
| MaxPool3 | 10×10×64 | 0 |
| Conv4，3×3，64→64 | 8×8×64 | 36,928 |
| MaxPool4 | 4×4×64 | 0 |
| Flatten | 1,024 | 0 |
| Dense，1024→128，ReLU | 128 | 131,200 |
| Dropout(0.1) | 128 | 0 |
| Dense，128→2，Softmax | 2 | 258 |
| **合计** | | **197,026** |

卷积参数：`(kernel_h×kernel_w×输入通道+1)×输出通道`，其中 +1 是偏置。第一层即 `(3×3×3+1)×32=896`。

全连接参数：`(输入维度+1)×输出维度`。第一层全连接为 `(1024+1)×128=131200`，约占总参数的 66.6%。这解释了为什么后续会考虑更小的分类头，但减少参数不保证效果变好。

Flatten 只是把 4×4×64 个值按固定顺序展开为 1024 个数；它既不学习权重，也不执行分类。真正的分类器是后面的 Dense 层。

## 5. 两个输出如何成为预测

原始 Keras 最后一层使用 Softmax，把两个分数转换为和为 1 的概率。例如原始分数 logits 为 `[1,2]`，Softmax 约为 `[0.269,0.731]`。

标签约定固定为 `NORMAL=0`、`PNEUMONIA=1`。若真实标签是肺炎，对应 one-hot 为 `[0,1]`，交叉熵为 `−log(0.731)≈0.313`；如果是正常，则为 `−log(0.269)≈1.313`。越确信错误标签，损失越大。

后续 PyTorch 同结构基线最后输出 **logits**，直接传入 `CrossEntropyLoss`，标签使用整数 0/1。不要先 Softmax 再传入这个损失，因为它内部包含相应的 log-softmax 运算。仅在评估和预测需要概率时做 Softmax。

## 6. 模型如何学习

每个 batch 执行：读取图像与标签 → 前向计算 → 计算损失 → 反向传播求梯度 → 优化器更新参数。反向传播用链式法则计算“哪个参数怎样变化会影响损失”；Adam 则根据梯度和历史统计量决定更新步长。

- **batch：**一次计算的一小组图像。
- **epoch：**把训练集遍历一次。
- **验证集：**选择最佳 epoch、检查过拟合，不用于计算训练梯度。
- **评估集：**配置确定后报告效果。本项目的原测试集曾被查看，称为开发评估。

原代码 batch size=10、epoch=5，没有独立验证集；训练生成器 `shuffle=False`。因此训练准确率上涨并不能证明泛化能力同步提高。新训练方案会统一预算和划分，但这属于下一阶段。

## 7. 如何判断分类器是否只偏爱多数类

肺炎样本在原训练集中较多。仅看准确率可能掩盖对正常类的误报，因此会同时看：

- 肺炎 Recall：真正的肺炎样本中，多少被预测为肺炎。
- Specificity：真正的正常样本中，多少被正确预测为正常。
- Balanced Accuracy：上述两个比例的平均值，让两类各占一半权重。

本阶段没有产生任何新模型指标。78.04% 仅是旧 Notebook 保存的历史准确率。
